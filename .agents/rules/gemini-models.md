# Gemini Model Versions

- **Gemini 2.5 Flash / Pro are outdated.** Do NOT suggest them.
- Current standards: **Gemini 3.5 Flash**, **Gemini 3.6 Flash**, **Gemini 3.7 Flash**
- When the user says "Gemini Flash", default to **Gemini 3.6 Flash** unless they specify otherwise.
- Backup model: **Gemini 3.7 Flash**
- Use `google-genai` SDK for all Gemini integrations.
